Capabilities

Thermal control architecture.

01 / ARCHITECTURE DIRECT SMC

Direct Hardware SMC

Connects directly to Apple Silicon System Management Controller (SMC) key registers to poll fan RPMs and thermal sensor matrix in real-time.

Zero Kernel Extension · User-Space Swift
02 / PROACTIVE TURBO HEADROOM

Proactive Pre-Cooling

Ramps fan speeds as workload begins rather than waiting for high junction temperatures, helping sustain peak CPU frequencies during long tasks.

Sustained Cinebench & Xcode Performance
03 / SAFETY 95°C OVERRIDE

Hardware Safety Override

Monitors temperatures continuously: if any sensor reaches 95°C, FanC immediately overrides manual profiles to maximum fan speed.

Dual Watchdog Thread · Fail-Safe Logic
04 / CLI AUTOMATION

fanc Command-Line Suite

Control and poll everything from the terminal: fanc status, fanc set 4500, or integrate into CI/CD scripts to pre-cool before massive builds.

Scriptable Output · JSON Control Channel
05 / TELEMETRY DUAL TACHOMETER

Dual Fan Visualization

Dedicated independent tachometer gauges for Left Fan and Right Fan (14" & 16" MacBook Pro and Mac Studio) with synchronized thermal heatmap chips.

Smooth 60fps Radial Rendering
06 / COMPATIBILITY ALL CHIPS

Apple Silicon Certified

Native optimization for M1, M1 Pro/Max, M2, M2 Pro/Max, M3, and M4. Automatically auto-tunes maximum RPM parameters based on the detected hardware model.

IOPlatformExpertDevice Auto-Detection
