Engineered for Performance

🌀

Smart Adaptive Curves

Five tuned profiles tailored for M1 through M6 chips. Smooth mathematical curves (ease-in pos², linear, S-curve) prevent annoying fan revving.

⚡

Proactive Heat Suppression

Anticipates thermal runaways by calculating thermal acceleration (dT/dt) in real-time, spinning fans early before CPU/GPU throttle trip points.

🛡️

Dual-Layer Hardware Safety

A hardcoded 95°C thermal floor forces 100% cooling if any cluster spikes. A 15s watchdog auto-reverts fans to Apple defaults if the app quits.

📊

Live Tachometer Telemetry

Dual fan tachometer visualizer shows live RPMs, power output percentages, and full thermal heatmaps for CPU, GPU, RAM, SSD, and ambient.

⌨️

Scriptable 'fanc' CLI

Query speeds, change targets, stream live telemetry, trigger calibrations, and export CSV sessions directly from terminal scripts.

🚀

Menu-Bar Native

Zero Dock clutter. Runs in background with standard bundle ID com.aoh.fanc to preserve macOS TCC permissions across builds.

How It Works

1

Read Every Cluster

FanC queries Apple's native SMC bus at 100ms intervals, aggregating thermal readings across CPU performance cores, GPU clusters, and memory.

2

Calculate Thermal Velocity

Rather than waiting until your chip throttles at 95°C, FanC detects rate-of-change and ramps up smoothly while heat is still dissipating.

3

Hardware-Safe Daemon Control

Fan commands are executed through a secure root daemon via /var/run/fanc.sock. If any sensor crosses 95°C, the daemon overrides instantly to 100%.

Installation

⚡ One-Click Terminal Install (Recommended)

The easiest and fastest way to install FanC. Copy and paste this command into your Terminal:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/arunofhyd/FanC/main/install-fanc.command)"

Manual Installation (Fallback)

  1. Download install-fanc.command file manually.
  2. Open Terminal (⌘+Space, type "Terminal", press Enter).
  3. Type sh — that's s, h, then a space.
  4. Drag and drop the downloaded file into Terminal.
  5. Press Enter to build and install FanC to /Applications.
user@macbook ~ % /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/arunofhyd/FanC/main/install-fanc.command)"
